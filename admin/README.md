# admin — 관리자 CMS (Vite + React + TypeScript)

Phase 2 에서 여기에 관리자 SPA 를 스캐폴딩한다. 현재는 비어 있다.

공개 사이트(`web/`)와 **완전히 분리된 별도 앱**이다.
결정 배경은 [docs/OPEN-DECISIONS.md](../docs/OPEN-DECISIONS.md) D-2 참고.

## 배치

```
admin.gymleco.co.kr        EC2 · nginx
  ├─ /          이 앱의 빌드 산출물 (정적 파일)
  └─ /api/*     Spring Boot 프록시     ← 동일 오리진
```

**API 와 같은 오리진에 놓는 것이 핵심이다.** 그래서:

- CORS 설정이 필요 없다
- 인증 쿠키가 host-only 로 발급된다
- `SameSite=Strict` 가 온전히 작동한다
- 관리자 코드가 공개 사이트 번들에 실리지 않는다

API 호출은 항상 **상대 경로**(`/api/...`)로 한다.
절대 URL 을 쓰면 동일 오리진 구성이 깨진다.

## 담당 범위 (기획서 §4.3)

| 화면 | 기능 |
|---|---|
| 제품 | 이름(한/영), 카테고리, 대표 이미지, 갤러리, 스펙(무게·치수·**설치 면적**), 설명, 정렬, 노출 on/off |
| 소식 | 제목, 본문 에디터, 썸네일, 발행일, 노출 |
| 문의 | 접수 목록, 상태(신규/연락중/완료), 메모, CSV 내보내기 |
| 설정 | 메인 히어로 노출 제품·순서, 연락처, SNS |

## 만들 때 지킬 것

**비개발자가 쓰는 화면이다.** 대표님이 개발자 없이 운영할 수 있어야 한다는
것이 CMS 를 직접 만드는 유일한 이유다(기획서 §4.1).

- 전문용어를 쓰지 않는다 ("슬러그", "메타데이터" 같은 말이 화면에 보이면 안 된다)
- 필수/선택 필드를 명확히 구분한다
- 이미지 업로드에 권장 해상도 안내를 붙인다
- 삭제·비공개 전환에는 확인창을 둔다
- 저장 전 미리보기를 제공한다

**보안**

- 리치 텍스트 에디터 입력은 **서버가 살균한 값만** 신뢰한다.
  프론트에서 `dangerouslySetInnerHTML` 을 쓸 때는 반드시 서버 살균을 거친 값이어야 한다.
- CSP 를 강하게 건다. 공개 사이트와 달리 여기는 정적 생성 제약이 없으므로
  `script-src 'self'` + nonce 로 갈 수 있다.
- 토큰을 `localStorage` 에 저장하지 않는다. 인증은 HttpOnly 쿠키로만 이뤄진다.
